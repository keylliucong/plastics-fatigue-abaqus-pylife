# 材料试验与疲劳标定：从试样到模型

本方案把已核对文献与 Abaqus/pyLife 方法串起来，帮助设计**目标牌号、目标成型工艺**的试验。它不指定未经证明的设计许用值；试样数量、应力水平、温度、停止判据和误差目标都需要结合零件和实际试验能力确定。正式试验应参照适用标准的有效文本，例如[单轴 ASTM D7791](https://store.astm.org/standards/d7791) 和[弯曲 ASTM D7774](https://store.astm.org/standards/d7774)，本方案不替代标准全文。

## 1. 先建立样品和工况台账

对每批试样记录供应商与牌号、批次、成型参数、取样方向、几何尺寸、调湿/老化条件和表面状态；对实际零件记录预紧、接触、载荷方向、波形、频率、环境、预期使用时间及失效定义。区别以下结果：裂纹起始、贯穿断裂、刚度下降、永久变形、夹持功能失效；不同判据不能不加区分地放进同一条寿命曲线。

先形成每个零件工况的“环境温度、实际载荷—时间、典型持续时间和预期局部应变”范围，用试验覆盖这些范围。没有零件测量或材料数据时，将后续数值标记为教学示例。

## 2. 两条并行数据链

```mermaid
flowchart LR
  A[材料与工艺一致的试样] --> B[加载 卸载 松弛 DMA]
  A --> C[恒幅疲劳与试样测温]
  B --> D[本构标定与独立验证]
  D --> E[Abaqus 局部历程]
  C --> F[逐试样疲劳数据及删失标签]
  E --> G[固定材料点历程与循环统计]
  F --> H[S–N 模型与不确定性]
  G --> I[候选损伤累计]
  H --> I
  I --> J[独立试样与零件验证]
```

**本构链**回答“给定应变和温度历程，应力怎样变化”；**疲劳链**回答“规定循环与失效判据下，试样何时失效”。二者必须分别采集和验证。一组 Prony 系数不能自动推出疲劳曲线。

## 3. 第一阶段：识别本构需要多复杂

| 项目 | 需要采集的原始数据 | 要判断什么 | 输出给下一步 |
|---|---|---|---|
| 多速率加载—卸载 | 时间、实际应变、应力、温度；在目标工作温度和至少两个有代表性的速率下测量 | 刚度是否随速率变化；卸载后的残余是否随恢复时间变化 | 弹性或时间相关模型的候选范围 |
| 多幅值松弛 | 实际加载斜坡和保载时程；不同目标应变水平、同一温度 | 归一化松弛形状是否随幅值明显变化；数据是否覆盖目标时间尺度 | 判断线性叠加是否有实验支持 |
| 蠕变与恢复 | 加载、恒载、卸载与足够长恢复期的完整历程 | 保载变形、延迟恢复和不可恢复成分 | 验证时间效应与预紧工况 |
| DMA（如适用） | 温度、频率、应变幅、$E'$、$E''$、相位和设备设置 | 频率与温度敏感性；与松弛数据覆盖范围的关系 | 辅助拟合和检查松弛谱 |

先用一组试验拟合，再用**未参与拟合**的加载速率、保持或卸载历程验证，并事先为关心的响应定义允许误差。记录试样及测量链的加载斜坡、采样和延迟；快速松弛若早于加载或采样分辨率，不能仅靠增加 Prony 项数识别。具体模型与示例见 [[塑胶本构关系说明 — 从文献到Abaqus建模]]。

## 4. 第二阶段：识别疲劳、温升和散热影响

### 4.1 恒幅基线

在固定材料、成型、方向、环境、波形和散热条件下，选择覆盖目标寿命范围的多个应力幅级；各级设置独立试样与重复，记录**每一件**试样的真实最大/最小载荷、时间、频率、温度、断裂或其他失效判据及停止循环数。先定义 run-out 终止规则和异常试样的处理原则，避免试后按结果临时更改。

为保证安全和设备适配，应力级通过材料初测和试验机构共同选定。重复数量和置信度不能凭文献中的少量样本照搬；先导试验只能用于筛选，不自动证明可靠的失效概率或耐久极限。

**为什么需要重复和独立验证？** [[08 FFF工艺与PC-ABS疲劳 — Rodrigues等 2026|Rodrigues 等]]的 FFF 试验中，PC 同一标称应力级的两根试样寿命分别为 520,942 和 834,070 次；作者的某些低周曲线又仅由图上两个点拟合，虽然图示 $R^2=1$，仍不足以检验预测能力。这不是目标 PC/ABS 的散布系数，而是说明单点结果和两点完美拟合都不足以定义可靠寿命。

**零失效结果如何解释：** 假设试样独立、同工况、预先固定截止循环数，零失效的单侧二项下限会随样本数量变化；[[疲劳试验数据与删失 — S-N拟合基础#3.3 全部 run-out 能证明多少可靠性？一个零失效算例|详细公式和示例]]说明，几个试样都未断裂不等于已证明高可靠度，更不等于无限寿命。实际试样数应基于目标、批次及试验设计确定。

### 4.2 频率与散热的先导对照

在**相同应力幅、应力比、波形、环境温度、试样及夹具**下，可以设计下面的 2×2 示例，比较两个项目关心的频率和两种可重复的散热条件：

| 条件 | 加载频率 | 散热条件 | 测量 |
|---|---|---|---|
| A | 低频 $f_L$ | 条件 H1 | 载荷、位移/应变、试样温度、环境、失效 |
| B | 高频 $f_H$ | 条件 H1 | 同上 |
| C | 低频 $f_L$ | 条件 H2 | 同上 |
| D | 高频 $f_H$ | 条件 H2 | 同上 |

$f_L,f_H$ 不是预设数值，H1/H2 应具体定义并记录气流、距离和温度。每个组合应使用独立试样，按实验能力安排重复并尽量随机或分块试验，记录设备与批次；不应对同一试样先后做四种条件后把它们当独立样本。若机器无法同时维持波形、幅值或夹持状态，应记录实际变化并重新评估对照有效性。表面红外测温需记录测点、发射率和视角；表面温度不自动代表内部峰值。

**看结果时区分三个问题：**频率变化是否改变力学响应；散热变化是否改变实际温升；温升、变形和失效模式如何共同变化。即使观察到相关性，也不能只凭四组先导试验认定某个单一失效机制，更不能把一组温升修正系数直接用于其他牌号。

这项对照借鉴 [[02 工程聚合物疲劳实现 — Volgers与Shojaei|Volgers 与 Shojaei]] 的 POM 散热试验及 [[07 聚合物自发热与损伤判据 — Katunin 2019|自发热综述]]；前者对照的峰值载荷接近但不完全相同，材料也不是 PC/ABS，因此以上是本项目试验设计建议，而非复述其完整试验矩阵。

### 4.3 标定与独立验证如何分开

在试验前明确模型将在哪些工况使用，再按试样、材料批次和制造批次建立标识及分组。**一个试样的整条加载—卸载—保载历程、温度和断口都属于同一组**；不能把同一试样的前半段用来拟合、后半段称作独立试样验证。需要评估同一试样后续响应时，可称为“同试样的时间外推检查”，并单独说明其局限。

| 目标 | 用于标定 | 验证时保留 | 需要报告 |
|---|---|---|---|
| 本构时间与速率响应 | 指定试样的拉伸、松弛或 DMA 数据 | 未参与参数选择的其他试样及有代表性的速率/保载路径 | 响应误差随时间、幅值和温度的变化 |
| 疲劳寿命及散布 | 指定试样的破坏和可纳入的删失记录 | 未参与模型形式、参数和修正系数选择的试样 | 每件预测与实测/删失、失效模式、曲线适用范围 |
| 批次与零件迁移 | 已知批次的试样与工艺信息 | 条件允许时，保留不同生产批次和独立零件试验 | 材料、加工、载荷和环境与标定的差异 |

同一注塑板切出的试样、同一批材料和同一设备试次可能存在共同因素；如果目标是验证跨批次能力，应按批次整体留出，而不是只把同一板上的试样随机拆到两边。只有一个批次时不能声称验证了跨批次泛化；样本不足时保留数据缺口，先做探索性验证。run-out 验证只说明实际寿命超过截止值，不应将截止次数当成实测失效寿命计算误差。

验证数据被用来修改材料参数、选择模型或调节疲劳修正系数后，该数据就不再是最终独立验证集；需要另外保留数据或明确将结果降级为调参后的内部检查。不同幅值和环境不能混在一起算单一误差而省略条件，失效位置和模式应与寿命一起比较。

### 4.4 探索能量型模型时，如何避免提前使用失效信息

[[17 短纤热塑性塑料疲劳准则比较 — Santharam等 2020|Santharam 等]]部分能量指标取自实测寿命中点 $N_f/2$。假设某试样最终在第 100,000 次循环断裂，那么事后可以回看第 50,000 次的数据；但要在试验开始时预测寿命，事先并不知道何时是 $N_f/2$。若先用真实寿命确定取值位置，再把该量输入模型，得到的结果只能用于描述或拟合已有试验，不能称为无需未来信息的前瞻预测。

若项目确需探索能量型方法，可以事先设计以下**候选验证方案**，而不是将论文中点指标直接用于零件：

1. **定义预测时刻和数据**：在实验开始前约定一个固定的早期循环数 $N_0$ 或实际运行时间，以及之前允许使用的温度、完整回线和平均应变增长等数据；$N_0$ 和信号质量要求由先导试验决定，不根据待验证试样最终寿命调整。
2. **先分组再设计**：按试样和需要的成型批次划分建模集和独立验证集。用建模集选择 $N_0$、指标、公式及系数并冻结；不要用验证集失效时间选取它们。
3. **明确预测对象**：采用 $N_0$ 时，模型只能在试样存活且数据可用到 $N_0$ 后给出条件预测；在 $N_0$ 之前失效或中止的试样要单独报告数量、原因和适用边界，不能静默删除后宣称适用于全部工况。预测目标应明确是总寿命 $N_f$ 还是剩余寿命 $N_f-N_0$。
4. **按真实信息顺序验证**：对独立试样只提供预测时刻前的数据，记录当时的预测及不确定性，再比较其后实际失效或删失结果、温度和失效模式。验证集的 run-out 只说明失效晚于截止点；不能用截止点冒充精确失效寿命。
5. **判断是否值得进入工程**：比较与只用载荷及匹配 S–N 曲线的基线是否有实际改进；模型若依赖无法在零件/有限元中可靠获得的信号，或对失效前早期样本覆盖不足，应记录局限并回到试验/模型设计。

这套流程是由文献证据提出的项目验证建议，**不是该论文已完成的独立前瞻验证**。模型系数、窗口、样本量和误差标准均须结合目标零件确定。

## 5. 数据进入 Abaqus 和 pyLife 前的审查

1. **本构参数**：保存拟合原始文件、参数含义、单位、温度、加载时间和有效范围；标记哪些实验用于拟合，哪些用于独立验证。对 $G(t)$ 与 $K(t)$ 分开列出证据及假设，不能把单轴 $E(t)$ 参数直接复制成剪切 Prony 参数。
2. **疲劳记录**：每件试样单独一行；`fracture=True` 表示符合预设破坏判据；经审查适合纳入右删失模型的未失效记录可用 `False`，并保留截止循环数与停机原因。计划 run-out 和因夹具打滑、温度异常或设备故障提前停止的试样不能自动等同：后者先标为待审或无效，判断停机与失效风险是否相关，并按预先规定处理，不能用布尔值掩盖原因。保留失效类型，不能将未断试样填成已断裂。[pyLife 2.3.1 数据示例](https://pylife.readthedocs.io/en/2.3.1/demos/woehler_analyzer.html)。
3. **适用性**：疲劳曲线与待计算历程要匹配幅值/范围、平均应力、温度、频率、制造状态和失效判据；没有足够证据的外推应显式标记，不能视为工程许可值。
4. **分区与拟合**：先打印 pyLife 的逐件分区和拟合样本，检查最高 run-out 对有限区的影响；对候选分区及统计模型做敏感性检查。[[疲劳试验数据与删失 — S-N拟合基础]] 给出可运行的虚构数据例子。
5. **独立验证**：在与标定不同的试样和零件条件下，对比反力—位移、局部应变/温升、失效位置与模式、寿命及散布。若不匹配，回到试验和模型假设，不通过随意调整一个寿命系数掩盖差异。
