# 知识库维护说明

## Zotero 文献索引

先启动 Zotero 并确保本机 Zotero CLI 可访问资料库，在终端运行：

```bash
python3 ~/Documents/Codex/塑胶疲劳知识库/工具/sync_zotero.py
```

这只预览；确认后运行：

```bash
python3 ~/Documents/Codex/塑胶疲劳知识库/工具/sync_zotero.py --apply
```

脚本读取项目主分类 JV64VS9S 及其全部子分类，按 Zotero 条目键去重，仅替换 [[Zotero 项目文献实时索引]]。它不写入 Zotero、不删除条目、不覆盖 `文献笔记/` 中已有的个人笔记。执行更新时，会为新增文献创建以题名命名的阅读笔记，并将条目键保留为属性和别名；预览时新条目显示为普通文字。查询失败时保留原索引。此过程是手动更新，不是后台实时同步；索引名称中的“实时”表示来自执行时的当前查询。

## 理论指南的版本

知识库中的 [[项目理论知识与阅读指南]] 与 GitHub 仓库 `docs/research/项目理论知识与阅读指南.md` 是两个独立文件，不会自动同步。2026-11-16 检查时两者 SHA-256 一致，已建立校验基线。先预览：

```bash
python3 ~/Documents/Codex/塑胶疲劳知识库/工具/sync_guide.py
```

若只有一侧发生修改，使用 `python3 ~/Documents/Codex/塑胶疲劳知识库/工具/sync_guide.py --apply` 同步到另一侧；若两侧均有不同修改，工具停止并要求人工合并。它只同步这份 Markdown，HTML 阅读版不会自动重新生成；也不会自动提交或推送 Git。项目仓库发生更新后，检查 `git diff`，再按项目流程提交与推送。

## Obsidian CLI

启动 Obsidian 并打开本库，终端示例：

```bash
obsidian vault='塑胶疲劳知识库' search query='Prony'
obsidian vault='塑胶疲劳知识库' read 'file=项目主页'
```

受运行环境权限限制时，自动化工具可能需要允许访问本机 Obsidian 进程。CLI 本身不提供 Zotero 自动同步。

## 模板

已在 Obsidian 核心插件中将模板文件夹设为 `模板`；可通过模板命令插入。模板包含文献、理论知识和项目决策三类。
