# 熵损伤模型为何会预测载荷顺序和停顿的影响？

Li, Fikry, Koyanagi, *Numerical Simulation for Durability of a Viscoelastic Polymer Material Subjected to Variable Loadings Fatigue Based on Entropy Damage Criterion*, 2024。[全文](https://www.mdpi.com/2073-4360/16/20/2857)；[DOI](https://doi.org/10.3390/polym16202857)；[Zotero](zotero://select/library/items/2EVJR4M9)。

**已阅读**：PDF 1–14页正文、表1–3、图题及文末；公式4–7通过出版社HTML交叉核对；已目视核对图7、10并追溯作者引用的部分前期研究。其他图曲线细节与前期论文完整验证尚待核对。本文研究对象是复合材料的**热固性聚合物基体单元**，不是PC/ABS零件。

## 作者的逻辑

将已发表的非线性广义Maxwell黏弹本构、熵型损伤和用户材料子程序结合，先用恒幅数值模拟构造基线，再设计多级与停顿载荷，将其模型中的结果与基于这条数值S–N曲线的Palmgren–Miner计算比较。[PDF p.2–3, 6–11]

研究使用Abaqus/Standard 2020、一个C3D8实体单元，轴向拉伸、R=0、2 Hz；模型包含15个Maxwell支路。[p.3–4] 原文将“振幅”与表2的 $\sigma_{max}$ 表述并用，参数复现前应确认加载上下限和幅值定义。

## 数学模型如何产生路径依赖

作者令黏塑性应变、损伤与应力历史耦合；松弛核由多个指数支路构成：

$$\mathbf E^r(t)=\sum_{n=1}^{15}\mathbf E^n\exp(-tE^n/\eta^n).$$

其中 $E^n$、$\eta^n$ 分别对应支路刚度和黏度；单支路的时间尺度量级为 $\tau_n=\eta^n/E^n$。表1第一支路 $E_1=284\,\mathrm{MPa}$、$\eta_1=450\,\mathrm{MPa\,s}$，得到 $\tau_1≈1.585\,\mathrm{s}$。这只是理解该参数化的手算，不是目标塑胶参数。[p.4–5, Eq.4, Table 1]

作者给出非线性因子

$$g=\frac{1}{1+\alpha(\sigma_{eqv}/\sigma_0)^m}.$$

按文中 $\alpha=2$、$m=7$、$\sigma_0=70\,\mathrm{MPa}$，当等效应力取70 MPa，$g=1/3$；取35 MPa，$g=1/(1+2/128)≈0.9846$。这说明材料参数在作者所选模型中如何改变速率分支；它不证明任意塑胶都满足此关系。[p.4–5, Eq.5, Table 1]

在论文恒温、忽略相应热传导项等假设下，熵产生简化为（文中 $\varepsilon^v$ 称为黏塑性应变，不应将其与任意可恢复的黏弹应变混同）

$$s=\int_0^t \frac{\boldsymbol\sigma:\dot{\boldsymbol\varepsilon}^{v}}{T}\,dt,$$

并采用 $D=\alpha_d(s/s^f)D_{cr}$。若采用作者的 $\alpha_d=4$，当 $s/s^f=0.25$ 时，得到 $D=D_{cr}$。这说明加速参数和临界阈值直接改变失效时刻；作者明确说明绝对循环数不是实际值，不能把数值算例寿命当作材料实测寿命。[p.4–6, Eqs.6–7]

## 结论所依赖的证据和不能外推的部分

| 作者提出的点 | 实际证据 | 证据边界 |
|---|---|---|
| 顺序/变幅可能影响寿命 | 在自定义模型中比较多种加载次序，部分情形早于由同模型恒幅基线得到的Miner预测。[p.6–10] | 本文重点是模型内部数值比较；并未在本文完成独立变幅试验验证，不能证明所有塑胶实际必然同方向变化。 |
| 停顿可影响损伤 | Pattern 5在特定谱中加入0.5 s停顿，模型预测的Miner寿命消耗比例为33.6%。[p.10–11] | 是该模型、参数和判据下的结果；不等于实际时间寿命也降低至33.6%，更不能当成通用设计系数。 |
| 统一加速不影响定性结论 | 作者主张不同工况相同加速可用于比较。[p.5–6] | 这是研究假设；损伤和黏弹演化时间尺度可能相互耦合，若未展示加速系数/阈值敏感性，就不能认为一般情况下比例自动保持。 |
| FFE是材料常量 | 作者引用既有研究提出这一假设。[p.4] | 本文未针对PC/ABS、多轴、湿度和温度变化证明常数成立。 |

**图7和图10的坐标复核**：纵轴是该模型的损伤变量 $D$，所选失效阈值为0.25；横轴为用恒幅基线寿命计算的 $\sum n/N_f$，不是绝对循环数或时间。图7四条曲线触及阈值时，正文报告依次为0.919、0.583、0.416、0.403；图10的带停顿 Pattern 5 报告0.336。图像与文中数值定性一致；各值只是模拟示例，不能作为材料实测临界 Miner 损伤。

**追溯模型先例**：本文参考的 [[14 CFRP熵损伤与载荷顺序 — Deng等 2023|Deng 等，2023]] 建立纤维/树脂分开的微观有限元模型，比较两级顺序的数值寿命；其第3.3节还指出另两种理论给出的顺序趋势与熵模型相反，作者提出需要进一步实验解释。因此“不同顺序可能影响预测”有模型证据，哪个顺序更危险仍需独立试验。另一篇被引的 [[15 聚酰亚胺黏弹损伤与保载 — Sato等 2021|Sato 等，2021]] 对聚酰亚胺及 CFRP 保载后强度做了实验与模拟比较，但作者明确当时只能进行定性对照；其网页全文已部分阅读，PDF和图像仍待核。这不等同于本篇不同幅值/停顿谱已被目标热塑性零件验证。

## 对工程SOP的意义

先用相同试样数据建立S–N/Miner并做独立两级、不同顺序和带停顿试验；若基线误差超出项目预设容差，再考虑带内部状态和时间的模型。保留真实时间、温度、载荷顺序、状态变量；不要用少量应力极值拼成完整历史。本文不证明pyLife自带FFE，也不支持把其Abaqus/Standard 2020的UMAT直接用于Explicit/VUMAT。
