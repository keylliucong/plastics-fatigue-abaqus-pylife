## 阅读和交付约定

Nature Paper X-Ray：来源范围、问题→方法→图表→结论证据链、反证/未报告项、关键公式的带单位手算、面向本项目的适用边界。最终报告需要对每篇材料说明证据等级；缺失全文不得伪称精读。最终SOP须含输入、操作、输出、检查、失败时处理、公式和引用。

补充检索：OpenAlex 对 2020 年 [Santharam 等论文](https://doi.org/10.1016/j.ijfatigue.2020.105574)列出作者稿及 [HAL 条目](https://hal.science/hal-03270375)；此前访问失败，现已通过 HAL API 取得文件地址并成功下载作者稿，已附 Zotero。2016 年 Chandran 和 2015 年 Mortazavian 两篇的 OpenAlex 记录标为非开放，不代表其他渠道一定不存在全文。
