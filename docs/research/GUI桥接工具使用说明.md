# ODB → pyLife 桥接工具（GUI）使用说明

## 使用场景

用户在 Abaqus 提交作业、生成 ODB 后，打开本工具，用鼠标点选 ODB、交互式设置参数、执行导出。
GUI 运行在与 Abaqus 隔离的 Python（项目 venv），ODB 读取通过 `abaqus python` 子进程完成
（PRD 方案 A：独立 GUI + 原生读取进程）。GUI 不直接加载 odbAccess，不修改原 ODB。

## 启动

在远程 Windows 上（需图形桌面会话）：

```text
E:\plastic-fatigue-bridge\.venv\Scripts\pythonw.exe E:\plastic-fatigue-bridge\bridge\gui.py
```

## 五步向导

1. **① 文件与环境**：填写 abaqus.bat 路径（默认 `E:\SIMULIA\Commands\abaqus.bat`）、
   点"浏览"选择 ODB，点"测试连接并扫描 ODB" → 列出步骤/帧/分量/截面点。
2. **② 数据选择**：选分析步（可点按钮自动填入）、区域（实例/单元集，留空=全部）、
   应力分量、帧范围（如 `0:-1`）。实体保留全部积分点，壳截面点按实际编号保留、不平均。
3. **③ 预览与单位**：确认源应力单位（如 MPa）、时间单位与含义（physical/pseudo/unknown），
   点"预览选中材料点历程"查看固定点应力序列（仅预览，不改变导出采样）。
4. **④ 疲劳参数**：可选关联一条已拟合曲线 JSON（首版不计算损伤）。
5. **⑤ 校验与导出**：选择输出目录，点"执行：探测→提取→独立重读核对→导出"。
   成功会提示桥接包路径；失败会显示问题清单，不产生标为完成的包。

底部可"保存工程配置/打开工程配置"，便于复用设置。

## 已验证（自动化调用链实测）

禁用弹窗后实测 GUI 背后调用链：扫描（1 步）→ 选择分析步（Cyclic）→
预览（1894 字符历程）→ 导出（32 点 / 416 行，manifest 生成）——全部通过。
同时验证了窗口构造（5 个向导页）无错误。

## 边界
- 需 Windows 图形桌面；SSH 无桌面会话时窗口无法交互，但调用链逻辑已实测。
- 无桌面会话下弹窗（messagebox）会阻塞，故自动化测试将其禁用。
- 单位由用户显式确认，未确认不得贴 MPa/秒标签；残余循环不闭合不计入损伤。
