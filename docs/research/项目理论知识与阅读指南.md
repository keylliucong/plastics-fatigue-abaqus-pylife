## 第1章：整个项目到底在预测什么【必读】

### 1.1 三个问题，三个不同的模型

**本构问题**：给定材料的应变、温度和历史，材料产生什么应力、残余变形及耗散？例如固定变形时夹紧力是否松弛。

**结构问题**：给定零件几何、装配、接触和外载，哪个材料点经历怎样的应力—应变—温度历程？Abaqus求解这一步。

**疲劳问题**：这样的局部历程持续多少次或多久，会触发约定的失效？pyLife可承担循环统计、曲线及损伤基线；更复杂的聚合物损伤可能需要额外模型。

三者的关系是：

```text
服役载荷 + 环境 + 制造状态
              ↓
试验 → 本构标定 → Abaqus局部响应 → 固定材料点的ODB历程
  ↓                                      ↓
疲劳数据 → 疲劳模型标定 → 循环/路径损伤 → 寿命与危险位置
                                              ↓
                          独立试验验证，必要时回到模型选择
```

仅有拉伸模量、屈服强度和一个静态应力云图，无法唯一确定疲劳寿命。建立了黏弹本构也不等于建立了疲劳损伤模型。

### 1.2 先约定“失效”

可选终点包括：首个可检测裂纹、裂纹达到规定尺寸、完全断裂、刚度降低到约定比例、永久变形超限、接触/夹持功能丧失。试样S–N数据对应的终点必须与零件预测目标一致。例如“刚度下降10%”和“完全断裂”的循环数不应混为同一寿命标签；10%只是判据示例，须由项目规定。

**本章产物**：一页问题定义表：目标材料/工艺、载荷和环境、失效判据、预测起点、输出寿命单位、验证方式。读完应能解释“算到断裂”与“算到功能失效”为什么可能需要不同试验。

## 第2章：力学、数学与热学前置知识【必读】

### 2.1 应力、应变与坐标系

应力σ是张量，不只是一个数。单轴σ=F/A；多轴状态包含正应力和剪应力。给定单位法向n，面力t=σn；法向应力σn=n·σn，剪切向量为t−σn n。这个投影是临界平面疲劳方法的基础。

小应变ε=(∇u+∇uᵀ)/2。有限变形要学习变形梯度F、J=det(F)、主伸长，以及Cauchy应力、第一/第二Piola–Kirchhoff应力。应力与应变必须采用功共轭的定义，不能把任意应力与任意应变相乘就解释为能量。

单轴均匀拉伸、尚未颈缩且近似体积不变时，工程量可近似转换为：σtrue=σeng(1+e)，εlog=ln(1+e)。出现颈缩、空穴化或明显体积变化后，这个简式不再给出局部真实应力，需截面测量或反演。输入某些弹塑性模型时还需从总应变中扣除弹性部分；不能把原始工程拉伸曲线直接当作塑性应变表。

局部坐标随材料旋转时，必须区分“同一材料方向的分量”与“固定空间方向的分量”。二者回答不同问题。壳的厚度方向和截面点尤其重要。

### 2.2 弹性常数与近不可压缩

各向同性小应变弹性满足σ=C:ε，由E和ν确定：

```text
G = E / [2(1+ν)]
K = E / [3(1−2ν)]
```

G控制剪切，K控制体积。当ν接近0.5时，K很大，位移型有限元可能体积锁死。不要仅因“塑胶”就一律设置ν=0.499；应依据目标温度、时间尺度和试验，并选择合适单元。

### 2.3 数据处理与参数识别

需要掌握对数坐标、最小二乘、加权拟合、残差、相关性、置信区间与参数可识别性。低残差不保证参数唯一：多个Prony谱可能都拟合同一段短时数据，却给出不同长期外推。

训练/标定数据用于确定参数；独立验证数据检验预测能力。材料拟合、疲劳拟合和整件验证应分别记录，不能用同一批数据完成三者后称为独立验证。

### 2.4 热学与时间尺度

热容量ρcp决定升温速度，导热系数κ决定内部热扩散，表面对流和接触导热决定散热。可比较加载周期Tload、松弛时间τ和热扩散时间L²/α（α=κ/(ρcp)）。De=τ/Tload是一个入门时间尺度比：小或大表示不同的松弛参与程度，但真实材料通常有一组τ，不能用单一De解释所有响应。

**本章产物**：统一单位表、应力/应变定义表、坐标约定。完成后应能说明为何MPa与Pa、范围与幅值、工程剪应变与张量剪应变的混淆会改变结果。

## 第3章：塑胶结构与本构模型的选择【必读】

### 3.1 先理解材料，不从软件菜单开始

聚合物链段运动、缠结、晶区、橡胶相、填料及界面共同决定宏观响应。Tg是玻璃化转变相关温区，受测试频率和判定方法影响；它不同于熔融温度Tm。PC/ABS是共混体系，配比、相容性、成型与热历史都会改变响应，不能为所有牌号共用一张“PC/ABS曲线”。

同一材料在低温/高速时可能更硬，在高温/慢速时更容易松弛与流动。注塑流动方向、熔接线、表层—芯层结构和残余应力会引入空间差异；FFF打印还包含层间结合、孔隙与路径效应。打印数据不能直接替代注塑件数据。

### 3.2 用可观察现象选模型

| 试验观察 | 候选本构 | 必须补充的证据 | 对疲劳路线的影响 |
|---|---|---|---|
| 近线性、卸载基本恢复、时间影响弱 | 线弹性基线 | 多速率/温度检查、循环稳定性 | 可先验证局部应力S–N基线 |
| 蠕变/松弛明显，小幅响应可叠加 | 线黏弹性、广义Maxwell | 多时间尺度松弛/蠕变或DMA | 要保留频率与真实时间 |
| 大变形可恢复，弹性非线性显著 | 超弹性，必要时黏弹分支 | 多种变形模式与稳定性 | 常需应变/能量指标，尤其弹性体 |
| 卸载残余变形、屈服、速率强化 | 弹塑性或黏塑性 | 多速率、拉压、卸载和循环试验 | 必须检查应力重分布和循环演化 |
| 累积软化、刚度持续下降 | 含内部状态的本构/损伤 | 多阶段循环、恢复/停顿试验 | 稳定单循环重复可能失效 |
| 明显方向相关 | 各向异性本构 | 不同方向数据与制造方向映射 | 方向相关疲劳曲线或指标 |

### 3.3 常见概念边界

- **弹性非线性**可恢复；**塑性**含不可逆变形；**黏性**引入时间/速率；**损伤**描述承载能力退化。这些概念可组合，但不能互相代替。
- 简单J2金属塑性可作为受限基线，却不自动包含玻璃态聚合物的压力敏感、拉压不对称、屈服后软化和取向硬化。
- Drucker–Prager一类压力相关屈服面也不因“压力敏感”就自动成为目标塑胶的完整循环模型。
- 橡胶超弹性、Mullins效应和撕裂能理论是弹性体分支，不能整体套到常温PC/ABS。

不同Abaqus材料行为能否组合取决于模型、求解器和版本；须查官方[Combining Material Behaviors](https://docs.software.vt.edu/abaqusv2026/English/SIMACAEMATRefMap/simamat-c-matmodels.htm)，并在2024做单元测试，不能简单把“弹性+Prony+塑性+损伤”全部勾上。

**阅读任务**：A1了解材料试验条件；A9了解玻璃态聚合物速率本构的研究入口。**本章产物**：模型选择记录，写出支持和否定每种候选模型的试验现象；不急于确定复杂模型的所有参数。

## 第4章：黏性、黏弹性与时间—温度理论【必读；非线性部分条件必读】

### 4.1 黏性与黏弹性不是同义词

理想一维黏壶：σ=η·dε/dt，η的单位为Pa·s。它描述速率相关耗散，停止应力后不提供弹簧式恢复。黏弹固体同时储存和耗散能量；卸载后可能逐渐恢复。实际塑胶还可能叠加不可恢复的黏塑性。

**蠕变**：保持应力，观察应变随时间变化，J(t)=ε(t)/σ₀。**松弛**：保持应变，观察应力下降，E(t)=σ(t)/ε₀。一般不能逐时刻用E(t)=1/J(t)转换，两者是不同边界条件下的响应函数。

### 4.2 从两个元件到松弛谱

以下为入门一维推导，初始状态取未加载：

| 模型 | 连接方式与方程 | 能解释什么 | 主要局限 |
|---|---|---|---|
| Maxwell | 弹簧与黏壶串联；dε/dt=(1/E)dσ/dt+σ/η | 阶跃应变后σ=Eε₀exp(−t/τ)，τ=η/E | 恒应力下长期持续流动，不宜独自描述平衡固体 |
| Kelvin–Voigt | 并联；σ=Eε+ηdε/dt | 阶跃应力后ε=(σ₀/E)[1−exp(−t/τ)] | 不能表示实际固体常见的瞬时弹性跳变和一般松弛 |
| 标准线性固体 | 平衡弹簧并联一个Maxwell支路 | 瞬时与长期刚度均可非零 | 一个τ不足以覆盖宽时间范围 |
| 广义Maxwell | 平衡弹簧并联多个Maxwell支路 | 宽谱松弛及频率依赖 | 分支过多易出现参数不可识别与外推问题 |

对阶跃应变，广义Maxwell的一维模量为：

```text
E(t) = E∞ + Σ Ei exp(−t/τi)
E0 = E∞ + Σ Ei
```

这段公式可由并联应力相加、各串联支路的同一应变直接得到。E0是瞬时模量，E∞是长期模量，两者必须与输入数据的定义一致。

### 4.3 线性黏弹的“线性”是什么意思

线性意味着小幅范围内可缩放、可叠加，不意味着响应与时间无关。对从静止开始的光滑加载：

```text
σ(t) = ∫₀ᵗ E(t−s) · dε(s)/ds ds
```

有初始应变跳变时需另计对应项，或使用包含跳跃的积分表示。历史通过卷积进入现在的应力，所以最大应变相同的两条历程可以产生不同应力。

做幅值扫描：如果归一化松弛曲线随幅值明显改变，或DMA模量强烈依赖幅值，不能继续把线性叠加当成已验证假设。入门推导建议阅读MIT的[Engineering Viscoelasticity](https://ocw.mit.edu/courses/3-11-mechanics-of-materials-fall-1999/d173f95347f59d59dd9b7387ab4303e7_MIT3_11F99_visco.pdf)，重点自己完成元件模型和阶跃响应练习，而不是直接借其例题参数。

### 4.4 DMA、复模量与耗散

小幅、稳态、等温正弦应变ε=εa sin(ωt)下，可写σ=εa[E′sin(ωt)+E″cos(ωt)]。E′是储能模量，E″是损耗模量，tanδ=E″/E′。在这一约定下，每周期单位体积耗散：

```text
Wd = ∮σ dε = π E″ εa²
```

这是由一个正弦周期积分得到的结果；不能直接套到大应变非线性回线、非稳定首循环或非等温循环。DMA测量的模量还与拉伸、弯曲、剪切夹具模式有关，剪切G∗和拉伸E∗不可不经假设直接互换。

### 4.5 Prony级数如何进入Abaqus

Abaqus时域黏弹通常用无量纲剪切/体积松弛系数与时间常数表述。剪切示意：

```text
G(t)/G0 = 1 − Σ gi [1−exp(−t/τi)]
G∞ = G0(1−Σ gi)
```

它与前述模量和式是同一种指数松弛表达的不同参数化。gi是相对权重，不能把Ei的MPa数值填进gi。体积项ki与剪切项gi含义不同。系数和的约束、瞬时/长期弹性输入选项及有限应变定义须查[Time Domain Viscoelasticity](https://docs.software.vt.edu/abaqusv2026/English/SIMACAEMATRefMap/simamat-c-timevisco.htm)，在2024按实际模型核对。

拟合原则：覆盖服役时间/频率窗口；先少支路再增加；检查非负时间常数与物理约束；用未参与拟合的蠕变/松弛或频率点检验。仅有一个常温拉伸模量不足以辨识完整Prony谱。短时拟合好也不意味着数年预测可信。

### 4.6 时间—温度等效与WLF

在热流变简单的适用区间，温度改变可近似通过时间平移表征。采用aT=τ(T)/τ(Tref)约定时，约化时间ξ=∫dt/aT[T(t)]。WLF形式：

```text
log10(aT) = −C1(T−Tref) / [C2+(T−Tref)]
```

温度差可用K或℃的差值，但绝对温度进入热激活公式时必须用K。C1、C2与参考温度及材料相关，不直接复制所谓通用常数。WLF原始论文见A8，当前核对了题名和DOI，未取得全文。

主曲线建立要检验相邻温度数据是否可合理重叠，是否需要垂直移位，以及不同机制是否具有不同移位规律。共混、多相、老化、湿度和相变可能破坏简单等效。黏弹主曲线能平移，不代表疲劳寿命也可按相同aT平移。

**本章产物**：松弛/蠕变/DMA原始数据表、时间与温度窗口、Prony参数及约束、独立验证图。**自问**：我的弹性模量属于瞬时还是长期？试验时长是否覆盖了零件周期和保载时间？

## 第5章：黏塑性、循环演化与热—力耦合【条件必读】

### 5.1 黏塑性需要额外的内部状态

小变形下可将总应变示意分为弹性、黏弹、不可逆及热应变，但具体分解必须属于一个自洽模型，不能随意拼接。黏塑性模型常涉及屈服/流动准则、速率函数、软化/硬化、压力敏感与内部变量；有限应变下还要学习乘法分解和客观率。

Eyring型热激活思想把流动速率与应力、温度联系起来。只作为概念示意，可写ε̇vp=ε̇0 exp[−Q/(RgT)]sinh(V∗σeff/(RgT))，这里Q和V∗采用每摩尔定义；若采用单分子定义，分母需改用kBT，不能混用单位。这不是本项目已经选定的PC/ABS本构方程。

Boyce–Parks–Argon文献A9是玻璃态聚合物速率依赖大变形本构的研究入口，需精读后再决定是否适合目标牌号；“有经典模型”不等于有可直接使用的材料常数。

### 5.2 循环稳定、棘轮与松弛

循环硬化/软化是回线随循环变化；棘轮是平均塑性/不可逆应变不断累积；循环蠕变常与平均应力、时间和温度耦合。载荷控制下软化可能增大应变，位移控制下松弛可能降低应力，因此两种试验不能仅比较名义幅值。

在Abaqus只计算一个循环再乘以百万次，必须先证明经过初始阶段后响应稳定，且温度、刚度、残余应变和接触状态没有持续演化。稳定应力不代表损伤一定停止，稳定温度也不代表材料不疲劳。

### 5.3 自发热与热失稳

单位体积能量平衡可用概念式表示：

```text
ρcp · dT/dt = div(κ grad T) + q̇diss + q̇other
```

真实稳态循环且耗散转热模型成立时，平均热源量级与f·Wd相关。不是所有数值耗散或外功都能当作材料热源；黏性、塑性、损伤储能和摩擦可能需分开处理。红外测量需考虑发射率、空间分辨率和表面/内部温差。

频率提高可能同时导致速率强化和自发热软化，二者竞争；因此“循环更快，寿命不变”不是聚合物的默认规律。A2、A3用于阅读自发热和频率影响，具体参数须以原文及目标试验为准。

### 5.4 子程序和加速算法的边界

UMAT、VUMAT接口中的应变度量、剪切约定、局部旋转、状态变量、能量和切线要求需分别学习。不能把UMAT改名为VUMAT就认为完成移植。先做单积分点/单元的恒速、卸载、松弛、循环及能量测试，再做零件。

循环跳跃、多时间尺度、降阶方法可减少计算，但必须检查损伤演化、温升、顺序效应和非稳定阶段是否被保留。A6、A7属于进阶研究，不能用其加速系数直接修正零件寿命。

**本章产物**：循环演化图、温度历程、是否需要热耦合/内部损伤更新的决策；若开发子程序，形成单元验证报告。

## 第6章：疲劳机理、试验与统计【必读】

### 6.1 聚合物可能怎样失效

需要区分裂纹萌生与扩展、银纹/空穴化、剪切屈服、界面脱黏、蠕变断裂与热软化失稳。疲劳试验中的“断裂”不一定来自同一种疲劳机理。A4针对具体聚合物实验讨论不同失效模式；读它的目的是学会辨认机制，不是把其HDPE/PVC参数搬给PC/ABS。

### 6.2 载荷定义必须一致

```text
Δσ = σmax−σmin          应力范围
σa = Δσ/2              应力幅值
σm = (σmax+σmin)/2      平均应力
R = σmin/σmax          应力比（σmax≠0）
```

R=−1常表示对称拉压，R=0表示零到拉伸，0<R<1常见于拉—拉。压缩主导及σmax接近零时要同时保存上下限，不能只记录R。完整一周期是cycle，反向次数是reversal；两者可能相差2。

频率、波形、保载时间、加载控制、环境温度和试样实际温度均应保留。“正弦5Hz”不能替代真实服役中带停顿的谱。

### 6.3 试验体系

| 试验 | 回答的问题 | 阅读入口 |
|---|---|---|
| 单调拉伸/必要的压缩 | 弹性、屈服、速率与拉压差异 | ASTM D638及匹配材料的适用标准 |
| 松弛/蠕变/DMA | 时间、频率、温度、线性范围 | ASTM D2990、D4065及适用分项 |
| 单轴恒幅疲劳 | 固定R、温度、频率下的寿命与散布 | ASTM D7791 |
| 弯曲疲劳 | 对应弯曲模式的疲劳行为 | ASTM D7774 |
| 两级/变幅/带停顿 | Miner、顺序和蠕变耦合是否适用 | 专门设计并记录加载序列 |
| 零件疲劳 | 几何、接触、制造与局部模型迁移性 | 与服役一致的验证方案 |

D7791与D7774分别面向单轴和弯曲塑料疲劳，不能不经分析互换。[D7791官方范围](https://store.astm.org/standards/d7791)、[D7774官方范围](https://store.astm.org/standards/d7774)。这里没有复述标准中的尺寸、样本数或机器要求；实施前须读获授权的标准全文。

### 6.4 最低记录字段

每个试样至少记录：牌号/批次/制造方式/方向、几何、调湿与老化、控制方式、σmax/σmin或εmax/εmin、名义应力计算截面、波形、频率、温度、循环终点、断裂位置、是否run-out、温升和异常。机器横梁位移不一定等于试样标距应变，需考虑夹具和机器柔度。

不同应力水平和重复试验应覆盖目标寿命区域，样本量由统计目标、标准和资源确定，本指南不虚构统一的“至少几件就够”。应设置一组独立验证数据，并随机化/分组控制批次与机器漂移。

### 6.5 Run-out、删失和不确定性

达到终止循环数但未失效的试样是右删失：知道Nf大于截止值，而非等于截止值，也不是已证明无限寿命。将run-out当作断裂点会改变拟合；全删掉又丢失信息。含删失的似然方法需写出分布假设、失效概率定义及拟合诊断。

对数正态或Weibull是候选统计模型，不能因软件支持就认定真实材料服从它。平均曲线、某存活概率曲线、均值置信区间与单件预测区间是不同对象。小样本尾部外推尤其需要独立依据。

pyLife拟合示例输入包含load、cycles、fracture，可作为软件学习入口；工程数据应保存真实试验状态，不能照搬示例按循环阈值猜断裂。[官方拟合教程](https://pylife.readthedocs.io/en/2.3.1/demos/woehler_analyzer.html)。另外ASTM E739-23在官方目录标为2024撤销，仅作历史统计参考，不能表述为现行要求。[官方状态](https://store.astm.org/products-services/standards-and-publications/standards/fatigue-standards-and-fracture-standards.html)

**本章产物**：试验矩阵、逐试样原始表、失效图片和状态标签、统计拟合说明。优先阅读A1—A4，再阅读与你材料类型相符的专门论文。

## 第7章：疲劳模型：S–N、应变、能量、裂纹和损伤【必读+分支】

### 7.1 应力寿命S–N与Basquin

在固定材料状态、R、温度、频率、失效定义及有效区间内，可拟合：

```text
σa = A Nf^b，b<0
或 σa = σ′f (2Nf)^b
```

这两种写法常数不同，必须保存N/2N约定。S–N是试验关系，不是只由弹性模量推导出的材料定律。拐点、双斜率和低应力段需要数据依据；没有断裂并不证明疲劳极限。

对于pyLife使用的正斜率参数k，单段幂律可重写为：

```text
N(σa) = ND (σa/SD)^(−k)
k = −1/b
SD = A·ND^b                 采用N形式时
SD = σ′f·(2ND)^b            采用2N形式时
```

这些式子由同一个幂律代数变换得到。ND/SD在本项目可被标为参考点，不能因接口用语就宣称实验上存在无限寿命平台。

### 7.2 均值、温度、频率与制造条件

优先建立与试验R等条件匹配的曲线，或拟合并验证条件相关模型。Goodman、Gerber、FKM等方法可作为比较对象，但金属经验不能未经验证用于塑胶。实测多R曲线优于凭一个抗拉强度自动生成所有均值修正。

温度/频率修正不只是对最终寿命乘系数：它们也会改变本构、局部应力和自发热。熔接线、缺口、表面、方向、残余应力和尺寸效应同样需要试样—零件迁移证据。

### 7.3 雨流计数

雨流把不规则标量历程转换为循环端点、范围、均值及次数。它做的是循环识别，不是材料损伤推导，也不保留所有时间顺序、保载和温度信息。

需要规定：转折点处理、噪声阈值、首尾残余半循环、谱块是否连续重复、分块时如何传递残余状态。对每个CSV块独立计数后直接相加，可能漏掉跨块闭合循环。滤波可移除真实损伤小循环，必须做敏感性比较；Nyquist条件只约束理想带限重建，不保证少量采样能准确恢复疲劳极值。

[ASTM E1049](https://store.astm.org/standards/e1049)提供循环计数方法的标准入口。其角色是规范计数概念，不为聚合物提供材料寿命参数。

### 7.4 Miner线性累积损伤

```text
D = Σ ni/Ni
谱块重复次数 Lblock ≈ Dcrit/Dblock
```

Ni是相应循环条件下的恒幅寿命。Dcrit=1可作基线假设，必须验证。相同循环集合换顺序，Miner计算不变；真实聚合物可能因过载、蠕变、温升与损伤状态不同而寿命不同。

折算小时还需要谱块的真实持续时间和重复规则。Dblock=0不自动代表实际无限寿命，应检查是否误设耐久平台、漏循环或单位错误。

### 7.5 应变寿命与能量指标【条件必读】

若局部塑性/非线性显著，可研究ε–N。金属常见Coffin–Manson–Basquin形式可作为认识弹性与塑性应变幅分解的入口，但不是已标定的塑胶公式。玻璃态聚合物的速率、温度和循环状态可能需要额外项。

能量法可用每周期耗散Wd=∮σ:dε、弹性能或其他物理指标关联寿命。必须区分可恢复储能与不可逆耗散、首循环与稳定循环、单位体积能量与整件能量。外力—总位移回线含夹具/接触贡献，不能直接当作危险点材料耗散。

### 7.6 多轴疲劳【条件必读】

非负Mises序列可能抹去拉压反转；最大主应力随时刻切换方向，也可能不是同一个材料方向上的历程。非比例加载还含相位和主轴旋转信息。可研究临界平面、拉伸/剪切组合指标、应变或能量准则，但需对应多轴试验。

应先在固定材料点保存完整张量及坐标信息，再决定标量评价方式，而非导出时只剩一个Mises最大值。短纤增强材料还要结合取向分布；A5是这一分支的阅读入口。

### 7.7 裂纹扩展与断裂力学【进阶】

若已知初始裂纹a0，目标是扩展到ac，可研究da/dN与ΔK、J或其他驱动力的关系。Paris形式da/dN=C(ΔK)^m仅在其适用区间、机制和条件下使用；聚合物可能有黏弹区、闭合、频率和温度效应。

裂纹扩展寿命与起裂/总寿命不是同一对象。需要裂纹测量、初始缺陷分布、几何驱动力及有效性检验，不能把裂纹试样参数直接当整件S–N输入。

### 7.8 路径相关损伤与熵方法【进阶】

内部损伤变量可随应力、应变、温度和历史演化，并反过来改变刚度/响应。能量/熵方法尝试以耗散或熵产生连接损伤，但临界值、耗散分解、恒温与加速假设仍需标定和验证。A6是在特定材料模型与算例范围内的研究，不是所有塑胶通用的失效理论。

**本章产物**：疲劳路线选择表、公式与条件、参数来源、拟合区间、外推规则、独立变幅验证计划。

## 第8章：Abaqus有限元理论与求解策略【必读】

### 8.1 有限元在求解什么

连续体平衡、运动学、材料本构和边界条件形成边值问题。位移通过形函数插值，单元积分点计算应变/本构响应，装配得到整体方程。静力问题可示意为R(u)=Fext−Fint(u)=0；动力学为Mü+C u̇+Fint=Fext。

刚度矩阵、积分点与节点插值是数值方法，不是材料真实微观结构。接触、几何非线性与材料非线性分别来自不同机制，应分开诊断。

### 8.2 Standard与Explicit如何选

| 问题特征 | 优先比较的方案 | 关键检查 |
|---|---|---|
| 缓慢加载、接触稳定 | Standard静力/适当准静态时变过程 | 收敛、真实材料时间、稳定化影响 |
| 黏弹松弛/蠕变且惯性可忽略 | 支持该本构的Standard时变准静态过程 | 总时长与增量能解析松弛过程 |
| 真实振动或惯性显著 | 隐式动力或Explicit | 动态响应、频率、时间步与阻尼 |
| 强接触、快速事件、极端非线性 | Explicit候选 | 稳定步长、惯性、能量及畸变 |

疲劳后处理不要求应力场必须来自Explicit。选择求解器是数值与物理决策，不是技术路线的固定前提。

Standard非线性问题通常迭代求平衡，需学习残差、切线、增量切回和收敛准则。Explicit用显式时间推进，单步便宜但条件稳定；无阻尼线性系统的教学稳定界为Δt≤2/ωmax，实际自动估计与接触/材料等有关。[官方显式积分理论](https://docs.software.vt.edu/abaqusv2026/English/SIMACAETHERefMap/simathe-c-expdynamic.htm)。数值稳定不等于时间精度足够。

### 8.3 真实时间、质量缩放与能量

对于速率相关材料，压缩加载时间会改变应变率与松弛，不能仅靠“动能较小”证明物理一致。质量缩放可提高稳定时间步而保留原加载时长，却改变惯性；应比较缩放量、局部应力、位移、接触和能量，不能只看单一比值。

用户已登录的官方2021帮助中，[Mass scaling](https://help.3ds.com/2021/English/DSSIMULIA_Established/SIMACAEGSARefMap/simagsa-c-qsimasscaling.htm?contextscope=all)明确讨论了速率相关材料不能靠任意提高加载速率提速，以及过度质量缩放带来的惯性误差。本次已在Edge阅读该页。它是理论学习资料，2024具体设置须另核对。

至少理解ALLKE、ALLIE、人工能量、黏性/阻尼耗散、外功与接触能量的含义；不要把所有数值耗散都当作材料发热。常见经验阈值只能作为筛查，不能单独证明准静态有效。

### 8.4 实体、壳与网格

实体适合三维局部接触和厚度应力；壳以中面、厚度和截面积分描述薄壁行为，必须核对法向与上下表面。薄壁外观不意味着壳能描述螺钉孔局部三维承压的一切细节。

学习完全/减缩积分、剪切/体积锁死、沙漏控制、厚度方向分辨率与子模型。网格收敛应比较目标历程或疲劳指标，而不只比较总位移。尖角、点载荷、刚性约束边缘的应力奇异性可能使最大应力随网格加密不断增大，应改进几何/载荷表达或采用经验证的局部评价方法。

### 8.5 边界、接触和循环输出

明确装配预紧、螺钉连接、摩擦、间隙、载荷方向、约束柔度及载荷相位。固定边界可能比真实夹具更硬，导致错误危险位置。

输出间隔必须保留循环极值和必要过渡。求解增量远小于输出帧间隔时，ODB仍可能漏峰；增加求解精度不会自动提高导出采样精度。先做帧间隔收敛，再做循环计数。

### 8.6 两类重构需要额外条件

线性、固定边界/接触和适当动力假设下可用单位载荷响应叠加重构；非线性接触、路径相关黏弹/塑性不能对单帧应力任意缩放。线黏弹虽具有叠加性，通常也需要考虑时域卷积或频率响应，不能简单用静态比例替代。

从少量稳定循环推算长期疲劳，需要先验证循环与温度稳定、损伤不显著改变响应。局部损伤演化明显时，单向“Abaqus一次→pyLife一次”可能需要升级为迭代/耦合流程。

**本章产物**：求解器选择依据、边界与载荷表、网格/时间/输出收敛结果、能量与响应检查。阅读顺序见附录B。

## 第9章：ODB数据、采样与桥接理论【必读】

### 9.1 ODB里的一条应力属于谁

基本层次为ODB → step → frame → field output → values。字段输出是空间场随帧变化，历史输出是选定区域/量的时间序列，不能假定两者都有相同采样和空间覆盖。

固定点标识至少包括instance、element label、integration point和shell section point；帧还需分析步和时间。两个实例可有相同单元号，壳上下表面也不能合并。官方[Reading field output data](https://docs.software.vt.edu/abaqusv2026/English/SIMACAECMDRefMap/simacmd-c-odbintroreadfieldpyc.htm)是字段遍历和位置属性入口。

积分点值、外推单元节点值与平均节点值是不同数据。每帧取全模型最大应力再拼接，会把不同材料点接成不存在的“虚拟历程”。

### 9.2 桥接必须保留的信息

| 类别 | 最少内容 | 缺失后果 |
|---|---|---|
| 身份 | 实例、单元、积分点、截面点 | 材料点混并或上下表面混并 |
| 时间 | step/domain、帧号、步时间、真实/伪时间语义 | 频率、保载与谱块小时数错误 |
| 张量 | 实际分量标签、输出位置、坐标基底 | 错误等效应力和拉压判定 |
| 单位 | 源单位、换算系数、标准单位 | 数量级与能量错误 |
| 有效性 | 缺帧、非有限值、删除/失效、STATUS可用性 | 人工闭合循环或掩盖失效 |
| 来源 | 文件指纹、版本、选择规则、参数与假设 | 结果无法复查 |

### 9.3 缺失、删除、坐标与精度

不能盲目补零、前向填充或跨断点雨流。删除单元导致的序列结束可能是失效信息，不是普通采样噪声。局部坐标旋转要按目标评价方向处理；首版桥接可保留原始信息并阻止未经验证的标量“就绪”标记。

CSV要保留足够数值精度与唯一键；大数据应分块，但分块不能丢失同一点的连续性。张量精度、坐标变换与符号约定应通过抽查和已知答案案例验证。

### 9.4 双Python环境

Abaqus的odbAccess由其自带运行环境读取ODB；现代Python环境承担pandas/pyLife和界面。版本、进程返回、文件协议和错误状态是桥接知识的一部分。独立环境隔离能够降低二进制兼容问题，但本身不保证数据正确。

本项目PRD的首版仅实现读取、选择、参数保存和导出，不含雨流和寿命。完整理论流程与首版工具边界应分开理解。

**本章产物**：数据字典、固定点样例、源ODB→交换包→pandas往返核对记录。

## 第10章：pyLife的数据模型和计算理论【必读】

### 10.1 pyLife的角色

pyLife是实现疲劳评估算法和数据操作的库，背后仍需要材料曲线、适用准则和验证证据。它不从ODB自动识别“这是什么塑胶”，也不自动生成目标牌号的有效疲劳参数。FKM相关模块的存在不构成其可直接适用于塑胶的依据。

### 10.2 pandas与材料点对齐

学习Series、DataFrame、索引与MultiIndex、长表/宽表、缺失值、连接和广播。推荐先用长表保持材料点与时间键，再形成单点历程和曲线对象。数组长度相同不意味着顺序一致；连接时按唯一键对齐，不凭行号假定应力、材料参数和网格属于同一位置。

### 10.3 WoehlerCurve

曲线由k_1、ND、SD等字段表达，低幅段k_2及散布等为其他参数。官方接口在k_2缺省时采用无限斜率的耐久假设，散布缺省也有软件默认值。本项目需要显式记录这些选择，避免把默认值当成试验证据。[WoehlerCurve API](https://pylife.readthedocs.io/en/2.3.1/materiallaws/woehlercurve.html)

采用单一直线、无平台的教学Basquin模型时，可显式令k_2=k_1，并限定拟合和外推范围。无散布数据时不能声称已建立可靠概率模型，即使软件能返回某个数值。

### 10.4 雨流检测器与记录器

pyLife将循环检测和记录分开：detector识别一维序列中的回线，recorder保存端点或统计。数据可以分块输入，但需保留检测器状态与首尾处理规则。官方还提示NaN处理可能影响索引；桥接层应在计数前检查缺失，不能依赖下游自动丢弃。[rainflow模块](https://pylife.readthedocs.io/en/2.3.1/stress/rainflow.html)

读者必须分清“记录循环端点”“生成幅值—均值载荷集”“对载荷集施加材料规则”。直接对原始张量DataFrame调用标量雨流并不完成多轴疲劳方法选择。

### 10.5 从载荷集到损伤

完整后续流程：单点标量序列 → 循环范围/幅值/均值/次数 → 条件匹配或验证过的修正 → Wöhler曲线给出Ni → 选定累积规则 → 单点损伤 → 按点键映射回网格。只有在谱块重复假设成立时才折算谱块寿命与小时。

[Life time Calculation教程](https://pylife.readthedocs.io/en/2.3.1/demos/lifetime_calc.html)展示曲线、载荷集、损伤与网格环节的组织方法。示例中的均值修正和材料数字仅供学习接口，不能沿用为本项目塑胶的标定结果。

### 10.6 版本与再现

本项目阅读基线为pyLife 2.3.1，不宣称它是最新版本。固定软件版本、依赖、公式、输入单位和处理规则；采用其他版本时核对API与数值行为。OdbClient/odbserver是桥接候选，不意味着其默认输出自动满足积分点和壳截面点的数据保真要求。

**本章产物**：一张输入—对象—公式—输出映射表；能在不依赖软件黑箱的情况下用手算解释一个循环的损伤。

## 第11章：贯穿项目的手算与最小验证案例【必读】

下面均为构造数据，只用于检查单位、定义和算法。

### 11.1 幅值与应力比

设σmin=10MPa，σmax=30MPa，则Δσ=20MPa，σa=10MPa，σm=20MPa，R=1/3。如果把20MPa范围误作幅值，对于k=5的幂律，给定次数下的损伤将放大2⁵=32倍。该结论由N∝σa^(−k)直接得到，与材料牌号无关。

### 11.2 Basquin与pyLife参考点

设σa=100·N^(−0.1) MPa，取ND=10⁶，则k=10、SD≈25.1189MPa；无平台单直线时k_2=10。输入N=10⁴应得到约39.8107MPa。若原式是100·(2N)^(−0.1)，则同一ND下SD≈23.4367MPa。用这两组答案检查N/2N转换。

### 11.3 松弛

设E(t)=1000+1000exp(−t/10)MPa，施加小阶跃应变0.01。瞬时σ≈20MPa；t=10s时σ≈13.6788MPa；长期趋近10MPa。真实FE施加有限上升时间时，应以同一加载斜坡的理论响应比较，而不是把阶跃答案强行套上。

### 11.4 Miner

假设某曲线给出两种循环的寿命N1=10⁵、N2=10⁶，一个谱块含n1=1000、n2=10000，则Dblock=0.02。若教学假设Dcrit=1，得到50个谱块；每块100s时约5000s。这个结果只验证计算，不验证真实变幅服役寿命。

### 11.5 必须逐级完成的验证案例

| 案例 | 要验证的知识 | 通过证据 |
|---|---|---|
| 均匀拉伸单元 | 应力、应变、单位和ODB读取 | 与F/A及设定本构一致 |
| 黏弹松弛单元 | Prony、初始/长期模量、真实时间 | 与同加载历史解析/独立积分一致 |
| 壳纯弯曲 | 法向、截面点与上下表面 | 表面符号和幅值分别正确 |
| 两实例同号单元 | 唯一点键 | 导出和回读不混并 |
| 完整重复正弦 | 采样、转折点和首尾规则 | 计数数量、范围和均值可解释 |
| 分块与连续计数 | 残余循环状态 | 在同样首尾约定下结果一致 |
| 已知曲线恒幅 | 曲线与损伤实现 | Ni与手算一致 |
| 两级载荷 | 累积模型适用性 | 仿真与独立试验比较，而非只验证公式 |

比较容差应由源精度、FE离散误差和试验噪声决定并预先记录。不要用“图看起来重合”替代数值核对。

## 第13章：可信度、适用范围与研究记录【必读】

### 13.1 区分三类误差

数值误差：网格、时间步、输出采样、舍入和求解控制；参数不确定性：模量、Prony谱、疲劳散布、摩擦等；模型误差：错误的损伤机制、忽略热/蠕变、试样到零件迁移失效。加密网格不能修复错误的失效机理。

### 13.2 敏感性与验证

先检查应力幅、S–N斜率、R、温度、接触/预紧、网格与谱重复对结果的影响。幂律下寿命对应力很敏感，小幅局部误差可能放大为寿命倍数；用对数寿命误差与散布表征通常更易解释，但具体指标应预先选定。

验证应同时看危险位置、局部应变/位移、循环回线、温升、失效形态和寿命。预测循环数偶然接近而失效位置/机理不同，仍不能视作已验证模型。

### 13.3 文献阅读和记录模板

每篇文献填写：材料/工艺；问题与终点；试验载荷和环境；本构/疲劳公式；参数来自哪张表或哪幅图；标定与验证是否分开；原始数据是否可得；适用条件；如何迁移到本项目；无法核实之处。

摘要、全文、复现是三个证据层级。AI skill是工作流程辅助，不是理论来源，也不提供材料认证。Nature类skill可帮助梳理证据；Abaqus skill帮助组织脚本；任何默认参数都仍需来源和验证。

**本章产物**：验证计划、适用范围声明、参数来源表、版本和文件校验记录。

### 自测题与判断要点

1. 只有PC/ABS的E、ν和抗拉强度能否计算可信疲劳寿命？——不能，还缺疲劳关系、条件和失效定义等。
2. 松弛和蠕变是否互为逐点倒数？——一般不是；边界条件和响应函数不同。
3. 如何判定线黏弹是否合适？——检查幅值线性、叠加、时间窗口及独立加载验证。
4. Prony的gi为什么不能填MPa？——它是相对瞬时模量的无量纲权重。
5. 静态夹紧力不变，塑胶应变为什么仍增加？——可能是蠕变；固定变形时则可能应力松弛。
6. 能否把显式分析从10s压到0.01s再恢复横坐标？——速率相关材料通常不能，计算出的响应已经改变。
7. ALLKE小能否证明疲劳应力正确？——不能，还需局部响应、时间/输出精度和材料验证。
8. 壳单元每帧取上下表面最大值为何有问题？——会把不同材料点拼接，丢失符号和历史身份。
9. Mises曲线为何可能丢失R信息？——非负标量不能完整保留拉压反转和多轴路径。
10. Run-out为何不是无限寿命？——它仅表明在该截止循环数前未达到终点。
11. 雨流为何不能替代蠕变/热模型？——它压缩循环统计，不保留全部真实时间和状态演化。
12. k_2不填会怎样？——pyLife曲线有耐久默认行为，需要显式选择并记录，不能当作材料结论。
13. 半循环怎样处理？——由首尾和重复规则确定，并通过已知信号验证，不能一律删除。
14. Miner为何无法描述顺序效应？——损伤只由循环计数和Ni累加，不含顺序状态变量。
15. 两种曲线N与2N如何统一？——保留表达式，用同一个参考循环数重新计算参考应力。
16. 什么结果才能称为零件验证？——独立条件下局部响应、温升/机制、位置和寿命共同支持，且声明范围。

## 附录C：术语与公式速查

| 术语/符号 | 含义 | 容易混淆的对象 |
|---|---|---|
| 本构 / 疲劳准则 | 局部响应规律 / 失效累积关系 | 黏弹本构本身不是疲劳寿命模型 |
| E0 / E∞ | 瞬时 / 长期模量 | 慢速拉伸测得模量不一定等于任一极限 |
| η / τ | 黏度 / 时间常数 | η有应力×时间量纲，τ是时间 |
| E′ / E″ / tanδ | 储能 / 损耗模量 / 损耗因子 | 不直接等于静态拉伸模量 |
| gi、ki | Prony剪切/体积归一化权重 | 不是以MPa计的分支模量 |
| aT / Tref | 移位因子 / 参考温度 | 必须保存移位正负号和时间约定 |
| σa / Δσ / σm | 幅值 / 范围 / 平均值 | 幅值=范围/2 |
| cycle / reversal | 周期 / 反向 | N与2N须区分 |
| run-out | 截止时未达到失效 | 不是已知断裂点或无限寿命证明 |
| k_1、k_2 | Wöhler曲线两段正斜率参数 | Basquin指数b通常为负 |
| ND、SD | 曲线参考/拐点的循环数和幅值 | 接口名称不证明目标塑胶有耐久平台 |
| D / Dcrit | 累积损伤 / 临界值 | Dcrit=1是需要验证的基线假设 |
| 材料点 | 固定实例—单元—积分点—截面点 | 每帧最大值的位置可变化 |
| 验证 / 标定 | 独立检验预测 / 估计参数 | 拟合好不等于独立验证通过 |
