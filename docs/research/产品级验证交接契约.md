# 产品级验证交接契约（由用户提供数据后执行）

状态：**等待输入**。本文件定义产品级验证所需的五项输入、格式、以及数据到位后的确切运行步骤。
方法学闭环（Abaqus 2024 求解 → ODB 桥接 → pyLife 雨流/损伤）已实机跑通，本阶段只替换输入为真实目标件数据。

## 五项必需输入（缺一不可，无法从环境推断，禁止编造）

### 1. 目标牌号恒幅疲劳试验数据
- 文件：`data/raw/<牌号>_sn.csv`
- 列：`load_amplitude_MPa`（应力幅，MPa；也兼容 `load`）、`cycles`（失效循环数）、
  `fracture`（True=断裂 / False=run-out；严格解析，混入 unknown 等标记会直接报错）。
  模板见 `realrun/TEMPLATE_sn.csv`。
- 要求：同一 R 比、温度、频率、成型工艺；应力幅需覆盖预期服役区间；run-out 需注明截止循环数。
- 处理：`fatigue/fit_sn_curve.py <csv> --out data/derived/curve_<牌号>.json --method maxlike`

### 2. 零件几何
- 文件：`abaqus/model/part.inp` 或 `.cae` 或 STEP（转 `.inp`）
- 要求：含真实材料牌号、成型方式（注塑/FFF）、厚度、取向/熔接痕说明。

### 3. 载荷谱时间序列
- 文件：`data/raw/load_spectrum.csv`
- 列：`time_s`、`channel_1`...（力/位移/压力，含单位）
- 要求：一个谱块的实际持续时间、重复规则、是否含保载/停顿。

### 4. 工况
- 文件：`data/raw/case_spec.json`
- 字段：材料牌号、R 比、频率 Hz、温度 ℃、环境（温湿度）、应力定义（幅值/范围）、失效判据。

### 5. 实测寿命（用于对比验证）
- 文件：`data/raw/measured_life.csv`
- 列：`specimen_id`、`cycles_to_failure`、`failure_location`、`failure_mode`、`temperature`
- 要求：独立验证件，未参与 S–N 曲线拟合。

## 数据到位后的运行步骤

```text
# 1) 拟合真实 S-N
.venv\Scripts\python.exe fatigue\fit_sn_curve.py data\raw\<牌号>_sn.csv --out data\derived\curve_<牌号>.json --method maxlike

# 2) Abaqus 求解真实零件（生成原生 ODB）
abaqus.bat job=part inp=abaqus/model/part.inp ask=off

# 3) ODB 探测
abaqus.bat python bridge\odb_probe.py <part.odb> --out data\derived\inv_part.json

# 4) ODB 提取（指定分析步/区域/分量；实体用 --basis global，壳按实际基底声明）
abaqus.bat python bridge\odb_extract.py <part.odb> <step> --component S11 --frames 0:-1 ^
    --basis global --out data\derived\bridge_part --meta data\derived\units.json
# units.json 至少声明源应力单位；缺失/未知单位会在第 6 步被拒绝：
#   {"units": {"stress_source": "MPa", "time_source": "s", "time_meaning": "physical"}}
# 同一目录重复导出默认拒绝；确认覆盖时加 --overwrite（会先清旧分块再发布）。

# 5) 独立重读核对（清单/哈希/组合键/帧覆盖/valid/基底）
.venv\Scripts\python.exe bridge\run_bridge_flow.py --verify-only data\derived\bridge_part

# 6) 雨流 + 损伤（用真实曲线；按 manifest 单位换算到 MPa）
.venv\Scripts\python.exe fatigue\analyze_real_bundle.py data\derived\bridge_part ^
    --curve data\derived\curve_<牌号>.json --component S11 --out results\product_damage
# 缺帧/valid=false/非有限应力的点逐点排除，summary.json 记录原因；
# 壳/梁截面点在基底未解析时拒绝计算。

# 7) 对比实测寿命，判定误差与失效位置是否可接受
```

## 判定规则
- 预测寿命与实测寿命的误差、散布、失效位置一致性按项目约定阈值判定。
- 任一步失败（NaN、键重复、缺帧、单位未确认）不得产出"完成"包。
- 曲线适用范围之外的外推需明确标注，不得当作已验证。
