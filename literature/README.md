## 使用方式

- `references.bib`：36条BibTeX导出，可导入Zotero等文献工具。
- `doi-list.txt`：论文、预印本与标准的DOI集合；不同来源DOI勿当作同一出版版本。
- `metadata/zotero-items.json`：条目与分类；`notes/<key>.md`：筛选、适用边界和下载记录。
- `pdf-manifest.json`：条目、文件、SHA-256与大小映射。
