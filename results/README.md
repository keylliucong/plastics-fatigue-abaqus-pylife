## synthetic_pipeline/（合成演练，非真实结果）

由 `fatigue/pipeline.py` 生成：合成桥接包经数据契约校验、逐点雨流、虚构 Wöhler 与 Miner 累计后的逐点损伤、寿命与校验记录。仅证明整条计算链的接口、单位与算术在本机可运行且可复核；不含真实 ODB、真实材料或可信寿命，不作为设计或验证依据。
